## 📂 Organización del Directorio de EPD

Este módulo centraliza todo el diseño pedagógico, normativo, instrumental y operativo de las **6 sesiones de Enseñanzas Prácticas y Desarrollo (EPD)** del cuatrimestre. La estructura se divide en material troncal transversal y carpetas específicas por sesión:

```
EPD/
├── General/                                      # Material troncal y normativo de todo el cuatrimestre
│   ├── cronograma_epd_psll_2026_27.md (.pdf)     # Cronograma oficial de las 6 EPDs y coordinación docente
│   ├── guia_estudiante_epd_psll.md (.pdf)        # Guía oficial del estudiante: metodología, evaluación y reglas
│   ├── manual_uso_app_laboratorio_epd.md (.pdf)  # Manual oficial de uso de la Web App del laboratorio
│   ├── PSLL_EPD_2026-27_propuesta.docx           # Propuesta y diseño docente integral
│   └── Material para definir contenido de EPD/   # Materiales de referencia y casos de trabajo docente
│
├── EPD 1/                                        # Sesión 1: Observatorio del Desempleo y Políticas Activas
│   ├── epd_laboratorio.html                      # Aplicación Web Interactiva del Laboratorio (EPD 1)
│   ├── manual_uso_app_laboratorio_epd.pdf        # Manual de uso de la app (copia de consulta de aula)
│   ├── Telemetria_EPD1_GoogleSheets.url          # Enlace a la telemetría de auditoría y entregas en tiempo real
│   ├── guion_video_informativo_epd1.md           # Guion técnico del vídeo docente introductorio
│   ├── prompt_ia_video_epd1.md                   # Prompts para la generación multimedia/IA del vídeo
│   └── registro_sesion_trabajo_epd1.md           # Registro de desarrollo y especificaciones de la sesión
│
├── EPD 2/                                        # (Próximamente · Semana 6)
├── EPD 3/                                        # (Próximamente · Semana 8)
├── EPD 4/                                        # (Próximamente · Semana 10)
├── EPD 5/                                        # (Próximamente · Semana 12)
└── EPD 6/                                        # (Próximamente · Semana 14)
```
